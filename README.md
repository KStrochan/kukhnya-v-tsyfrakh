# Кухня в цифрах

Лендинг застосунку «Кухня в цифрах» (kuhnyavcifrah.shop): калькулятор собівартості й фуд-косту для кафе і піцерій. Сам застосунок — окремий приватний репозиторій `kukhnya-v-tsyfrakh-app` (app.kuhnyavcifrah.shop).

Статичний сайт без збірки: HTML + CSS + JS-модулі, шрифти — у `fonts/`. Заявки на оплату доступу обробляє серверна функція Vercel `api/order.js` і надсилає листи через Gmail.

**Дизайн.** Таблиця як матеріал: жовта клітинка — це акцент, кнопка і живий елемент. Перший екран — відео піци й техкарта, що заповнюється. Далі піца збирається під час скролу (5 шарів, собівартість рахується разом із нею, фінал — 38,3% фуд-кост) і калькулятор: дві жовті клітинки перераховують фуд-кост, рекомендовану ціну і гроші за місяць. У блоці «Що вміє застосунок» — справжні скріни застосунку з прикладом піцерії (`img/app-*.webp`). Анімації — `assets/js/motion.js`; без JS і з «зменшити рух» сторінка показує все статично.

## Оплата

7 днів після першого входу застосунок безкоштовний. Далі — доступ на місяць (199 грн) або рік (1 490 грн). Онлайн-еквайрингу немає, тому:

1. Покупець у блоці «Тарифи» обирає місяць чи рік, вводить email і бачить номер картки (змінна `PAY_CARD`), платить переказом через EasyPay і натискає «Я оплатив(ла)».
2. Вам приходить лист «Перевір оплату …» з готовою командою SQL. Покупцю — «Перевіряємо оплату».
3. Коли гроші надійшли: Supabase → проєкт застосунку → SQL Editor → виконати команду з листа, наприклад
   `select code from public.issue_access_codes(1, 30, null, 'buyer@gmail.com · Доступ на місяць');`
   (365 замість 30 — для року).
4. Надіслати код покупцю на пошту. Він вводить його в застосунку на сторінці «Ще», дні додаються до поточного доступу.

Тарифи (сума й кількість днів) задаються лише в `api/_product.js` — зі сторінки приходить тільки назва тарифу. Код — `assets/js/pay.js`, `assets/js/main.js` і `api/order.js`.

## Деплой на Vercel

1. New Project → імпортуйте цей репозиторій. Framework Preset: **Other**, Build Command порожній, Output Directory — корінь.
2. Settings → Environment Variables:
   - `SMTP_USER` — Gmail, з якого йдуть листи (краще окрема скринька під бренд);
   - `SMTP_PASS` — пароль застосунку для цього Gmail: Google-акаунт → Безпека → Двоетапна перевірка → Паролі застосунків (16 символів, без пробілів);
   - `PAY_CARD` — номер картки, на яку покупці переказують гроші через EasyPay. Без нього форма працює як заявка: вам приходить лист, а ви самі пишете покупцю, як оплатити;
   - `OWNER_EMAIL` — куди надсилати сповіщення про продажі (необов'язково, за замовчуванням — `SMTP_USER`);
3. Redeploy.

## SEO

- `title`, `description`, canonical, Open Graph і Twitter-картка (`img/og.png`, 1200×630).
- JSON-LD: Organization, WebSite, SoftwareApplication з тарифами, FAQPage.
- `robots.txt`, `sitemap.xml`, `site.webmanifest`, favicon SVG.
- Шрифти віддаються з власного домену з довгим кешем, а CSS і JS — з перевіркою свіжості при кожному заході (`vercel.json`), щоб після оновлення ніхто не отримав стару версію скриптів.

**Домен** — kuhnyavcifrah.shop (DNS у GoDaddy: A `@` → Vercel, CNAME `www` і `app` → Vercel). Адреса прописана в `index.html`, `privacy.html`, `oferta.html`, `robots.txt` і `sitemap.xml`.

## Що доробити перед запуском реклами

- Вставити код Meta Pixel у `<head>` (місце позначене коментарем).
- Дописати контакт для звернень у `privacy.html` і `oferta.html`.
- Після реєстрації ФОП — онлайн-оплата з автоматичною видачею коду (monobank, WayForPay, LiqPay); місце під webhook уже є в застосунку.
